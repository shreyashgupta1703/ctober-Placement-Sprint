# Shreyash — October Placement Sprint

A personalized static GitHub Pages dashboard for October 2026 placement preparation.

## Daily structure

- **8:30–12:30:** DSA, including a 30-minute SQL block on study days
- **1:30–5:30:** Projects / GenAI / RAG / ML
- **6:30–10:00:** Core CS / HLD / LLD / revision

## Half-day resets

**October 5, 10, 14, 21, 26, 31** are half-day study days with **no DSA**. The project and Core/Design blocks remain available.

## October progression

- DSA: first 4 days are focused revision of DP, Graphs, Trees, Stacks/Queues; then remaining Striver questions are cleared through October 13; after that DSA becomes maintenance + POTD + weak-topic practice.
- Projects: Customer Churn → LangChain/LangGraph → Vector DB/RAG → Deep Packet Inspection → Offline UPI/Spring Boot.
- Core: CN 2 days → DBMS 2 days → OS 2 days → OOPS 2 days → buffer/practice → HLD + LLD in roughly 5–6 days → remaining evenings for revision and practice.

## Run locally

Open `index.html` in a browser. Progress is stored in `localStorage` for that browser.

## GitHub Pages

Create a public repository, upload `index.html` and `README.md`, then enable **Settings → Pages → Deploy from branch → main → / (root)**.
